# TAKE HOME TEST NUTECH

## Description

Technical test to be done at home to create a REST API with a SWAGGER contract. This service consists of UserService, TransactionService, and InformationService. The UserService is intended for user purposes, including registration, login, photo upload, and profile editing. The InformationService is for viewing banners and the services provided. Lastly, the TransactionService is for topping up, checking balance, and purchasing services.

## Features

- User Service
- Transaction Service
- Information Service

## Technologies Used

- **Programming Language**: Java 21
- **Framework**: Spring Boot
- **Database**: PostgreSQL
- **Build Tool**: Gradle
